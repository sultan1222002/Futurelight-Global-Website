# FutureLight Global — Website

Official website for FutureLight Global, a study-abroad consultancy based in Cumilla, Bangladesh.

## Stack
- Next.js 16 (App Router, TypeScript)
- Tailwind CSS v4 — "Night Harbor" design token system (deep navy base, amber "beacon" accent, "skyway" blue)
- Self-hosted Poppins / Inter via `@fontsource`

## Getting started
```bash
npm install
npm run dev
```

## Status
Foundation + homepage built from the project PRD. See commit history for progress.
